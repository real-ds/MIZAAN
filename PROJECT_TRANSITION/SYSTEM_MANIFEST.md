```markdown
# Company Development Standards

## Code Review Requirements
- All PRs need security review for: auth, database, payments
- Performance review required for database queries
- Minimum 1 approval before merge

## Technology Stack
- Backend: [Your choice]
- Frontend: [Your choice]
- Database: [Your choice]
- Cache: [Your choice]
- Message Queue: [Your choice]

## Naming Conventions
- Tables: snake_case
- Classes: PascalCase
- Functions: camelCase
- Constants: UPPER_CASE

## Required Logging
- All errors logged to [service]
- All API calls logged
- All database queries timed
- All failures have unique error codes
```

```markdown
## API Endpoint Pattern

3. Add service method in user_service.py
4. Add validation in validators.py
5. Add tests (unit + integration)
6. Update API.md
7. Update CHANGELOG.md
```
